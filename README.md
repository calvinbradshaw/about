### Development Stack & Architecture

- **Frontend & UI:** TypeScript · React · Vite · Tailwind CSS
- **Backend & Data:** Supabase (PostgreSQL, Row Level Security, Edge Functions)
- **Edge & Hosting:** Cloudflare Pages & Workers · GitHub Actions CI/CD
- **Integrations:** REST APIs · Webhooks · GraphQL

> [!NOTE]
> **Speed matters because slow software gets worked around.** When a system is sluggish, people go back to paper and spreadsheets. These are lean static builds served from the edge, so pages load instantly even on a shop-floor tablet, with fewer moving parts to maintain or patch. Access control is enforced in the database itself (Postgres RLS).

> [!NOTE]
> **Ownership matters because per-seat costs punish growth.** SaaS charges more every time your team grows. Software built to be owned outright has no per-seat fee: the running cost is a small, predictable monthly database charge that doesn't climb with the number of users. The result is a permanent operational asset that serves the business for years.
